# Agent instructions

This repository is **Breure.ai**.

**Breure.ai builds focused custom software for maritime workflows.**

Before substantial work involving brand, design, UX, product, architecture, content, SEO, GEO, navigation or positioning, **read `docs/BREURE_AI_DNA.md`**.

That file is the primary brand/product decision document. This file does not replace it.

## If docs and code disagree

Do **not** automatically restore old documentation behaviour.

The public site after the 2026 maritime-software repositioning is the current truth unless `docs/BREURE_AI_DNA.md` has been updated more recently. Check whether the documentation is outdated first.

`docs/archive/` holds historical documents. Do not treat archived files as current strategy.

## Hard boundaries

- Breure.ai = maritime software. TableWorks = restaurant technology. Do not mix them.
- Do not present Breure.ai as a web agency, webbureau, horeca brand, or generic AI agency.
- Company voice is `wij` / `we` / `Breure.ai`. No solo-founder positioning. Do not invent team size.
- Do not fabricate clients, testimonials, fleets, awards, or usage numbers.
- The Vessel Comparison Tool is a **demo** with fictional data, not a client case.
- Do not promise every project in one week. Tightly scoped work can often have a first version in days.
- AI is an enabling technology, not the product.
- Do not reintroduce Horeca, Hospitality, generic Services, Portfolio, Process, or Tools into primary navigation without an explicit strategic decision.
- `/horeca` may stay live for migration safety. Do not promote it. Do not redirect to TableWorks until the production TableWorks URL is approved.
- Do not redesign the whole site, add large dependencies, or refactor stable code without a reason.
- Do not deploy or commit unless explicitly asked.
